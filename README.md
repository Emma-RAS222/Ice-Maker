# IDEA Ice Tube Maker — One-page website

A responsive, single-page website made with **plain HTML, CSS, and JavaScript**. No frameworks, package manager, build step, or compilation required.

## Files

- `index.html` — page content and contact/order form
- `styles.css` — blue water-inspired responsive design
- `script.js` — mobile navigation, product selection, and email order inquiry

## Run locally

Open `index.html` in a browser. No server or installation is needed.

## Before publishing — customize these demo details

1. **Prices:** The listed prices (₱25 / 1 kg, ₱100 / 5 kg, ₱180 / 10 kg) are sample rates. Update them in `index.html`.
2. **Phone:** Replace `+63 912 345 6789` and the `tel:` link in `index.html`.
3. **Email:** Replace `hello@ideaice.example` in `index.html` and `script.js` with your real business email. The `.example` address is intentionally a placeholder and will not receive mail.
4. **Facebook:** Replace the Facebook link with your business page URL.
5. **Delivery terms:** Update the delivery/pickup information and minimum order details to match your business.

The order form opens the visitor's default email app with a pre-filled message. It does **not** send orders to a server or store customer data. If you prefer orders through Messenger, WhatsApp, or a hosted form service, update the contact action accordingly.

## Publish with GitHub Pages

1. Create a GitHub repository, for example `idea-ice-tube-maker`.
2. Upload `index.html`, `styles.css`, `script.js`, and `README.md` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under the build/deployment source, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish your site. The URL will appear in the Pages settings.

No build command is required.
